# Skills

Each folder here is one guide, written once: a person reads it on GitHub, and an agent's tooling
loads the folder as a skill. The block at the top of each file, with a `name` and a
`description`, is the form agents expect. The engine's own guides (writing a template, using
Heliograph, diagnostics) are in the
[Heliograph repo](https://github.com/jonnymuir/Heliograph/tree/main/docs/skills).

| Guide | For |
|---|---|
| [reference-site](reference-site/SKILL.md) | Anyone trying Heliograph in Umbraco, and a developer joining it to Wayfinder |
